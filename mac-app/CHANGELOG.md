# История версий

Каждому релизу соответствует версия приложения, аннотированный Git-тег `vX.Y.Z` и
описание изменений. В монорепозитории коммит содержит префикс `mac-app vX.Y.Z`.
Публичный репозиторий имеет отдельную историю без истории личного контента.

## 0.6.1 — 2026-11-02

- Проверка героя отклоняет резкие повороты головы и изменение масштаба лица.
- До четырёх попыток на план: причина отказа меняет инструкции следующему дублю.
  Требования к артикуляции, масштабу и положению головы накапливаются.
- Статус показывает причину и номер попытки; отчёт сохраняет seed, prompt и меры.
  Ранее созданные дубли и отчёты не перезаписываются.
- Пороги качества не ослабляются; исчерпание попыток останавливает монтаж.
- Новый ML inference не проверен. Эвристики не подтверждают точный липсинк и сходство.
  Полный перезапуск пока повторяет синтез; внутри цикла дублей озвучка сохраняется.

## 0.6.0 — 2026-11-02

- Длинные тихие интервалы ESpeech сокращаются до 0.35 с без ускорения речи.
  Исходные WAV сохраняются; правки и повторный аудит записываются в timing-check.json.
- Для TTS «Битрикс24» явно читается «Би́трикс два́дцать четы́ре»;
  исходный сценарий и субтитры не меняются.
- MediaPipe отсеивает дубли героя с почти неподвижным ртом или потерянным лицом.
  После одной повторной попытки неудача останавливает монтаж. Отчёты и дубли сохраняются.
- Проверка движения рта не подтверждает точную синхронизацию. Новая полная
  генерация ролика и прослушивание исправленного произношения ещё не выполнены.
- Добавлены тесты пауз, чтения названия и проверки движения рта; обновлены
  зависимости compositor и список публичного экспорта.

## 0.5.0 — 2026-11-01

### Голос и пайплайн

- Общий production worker переведён с Qwen 0.6B на ESpeech/ESpeech-TTS-1_RL-V2.
  Ранее ESpeech подключался только в отдельных сценарных сборках.
- ESpeech использует отдельное существующее окружение, словарь ударений, написания
  для TTS и cooperative cooling между шагами диффузии. Исходный текст и субтитры
  не изменяются написаниями для синтеза.
- Темп синтеза 1.0, без автоматического atempo. Предыдущая отдельная проба +5%
  не применяется ко всем роликам автоматически.
- Qwen worker сохранён отдельным исходником для воспроизведения истории.
- Проверка зависимостей соответствует ESpeech; режим только голоса не требует
  наличия моделей LTX/Gemma. Добавлен read-only doctor: импорты, пути, инструменты.
- Provenance отчёта включает ESpeech, версию и хеши новых файлов настроек.
  Запуск из архива исходников допускает отсутствие Git-метаданных.
- Сохранены speech-first timing, контроль пауз >=0.85 с, лимит 90 секунд,
  отдельная зона субтитров, декод MP4, тепловой контроль и остановка дочерних процессов.
- ThermalGuard создаёт рабочий каталог перед компиляцией thermal-state.

### Списки и фото

- GUI импортирует JSON-массив (или объект items), CSV и несколько TXT-файлов.
  JSON понимает title/source/script/speech; CSV — title/script либо Название/Сценарий.
- Предпросмотр названий перед загрузкой, явное отображение числа сценариев,
  возврат в одиночный режим. Пакет из 30 ранее подготовленных разборов совместим.
- До генерации проверяются все сценарии и входы. Максимум 100 сценариев,
  5 MB на входной файл. Данные не исполняются как код или команды.
- Папка случайных фото работает для списка и одного сценария. Проверяются файлы
  верхнего уровня PNG/JPEG/WebP/TIFF/BMP; повреждённые пропускаются.
- На каждый ролик выбирается один случайный снимок с возможными повторениями.
  Снимок копируется в задание; при продолжении очереди выбор не меняется.
  Голос берётся из подключённого профиля, не из папки снимков.
- Задания исполняются последовательно, каждый имеет конфигурацию, журнал и статус.
  Ошибка останавливает очередь. Продолжение пропускает завершённые задания.
  Дополнительный lock не позволяет одновременно продолжать одну очередь.
  После upload_error повторяется только загрузка, без повторного ML-инференса.
- GUI остановка завершает текущий worker и оставляет остальные задания в очереди.

### Сборка и открытые исходники

- Версия GUI/Info.plist/документации: 0.5.0, build 9.
- Сборка использует исходник векторной иконки; личный PNG больше не нужен.
- Нейтральный bundle identifier; старый сохранённый выбор профиля может потребовать
  повторного подключения через «Подключить папку аватара».
- Добавлены MIT LICENSE для собственного кода, список внешних компонентов,
  инструкции зависимостей, примеры, .gitignore и правила публикации по allowlist.
- Публичная поставка исключает личные портреты/голос, профили, SQLite, jobs,
  результаты, модели, окружения, токены, абсолютные пути владельца и старую Git-историю.
- Тестовые фото и аудио создаются синтетически: приватные fixtures больше не нужны.

### Проверки и пределы

- 21 Python unit/integration tests: parser, history, pronunciation, pipeline delivery,
  сохранность результата при ошибке upload, batch import, выбор/снимок фото,
  продолжение и остановка на ошибке. ML в тестах оркестрации замокан явно.
- Swift release build и ad-hoc codesign, read-only runtime doctor.
- Проверки реального ESpeech и compositor фиксируются в VALIDATION.md по результату.
- .app привязано к рабочему каталогу: модели/окружения не включены. Это исходный
  macOS-проект, не переносимый установщик. Developer ID/notarization не выполнены.
- Качество тембра, лица и артикуляции требует прослушивания/просмотра человеком;
  успешные тесты не доказывают художественную пригодность ролика.

## 0.4.0 — предыдущая локальная версия

Существующие возможности: AppKit GUI, профиль аватара, parser структурированного
сценария, библиотека SQLite, Qwen worker, LTX-планы героя, анимированная графика,
монтаж по речи, CLI, необязательная загрузка rclone. Отдельного публичного релиза
0.4.0 не было; исторические коммиты монорепозитория сохранены без переписывания.
