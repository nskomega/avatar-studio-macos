# Проверки 0.5.0 — 1 ноября 2026

## Выполнено

- 21 Python tests прошли: parser, SQLite, ударения, CLI detach, pipeline delivery,
  upload failure, batch JSON/CSV/TXT import, входные ограничения, пропуск битых фото,
  сохранность выбранного снимка, продолжение очереди, пауза при ошибке и повтор только upload после сбоя загрузки.
- Swift profile smoke: профиль, относительные пути, отсутствующий портрет, извлечение
  речи и ограничения длины — passed.
- Полный пакет 30 сценариев импортируется parser-ом: 30 подготовленных планов.
- Swift release build 0.5.0 build 9, ad-hoc подпись.
- Runtime doctor: импорты compositor, ESpeech и LTX, FFmpeg/ffprobe/macmon,
  наличие весов, словаря и thermal-state — passed.
- Реальный ESpeech worker через общий pipeline создал короткую тестовую речь,
  timing audit прошёл. Синтез 1.0 без atempo; cooperative cooling работало.
- Реальный compositor создал 4-секундный MP4 на синтетическом цветном видео/тоне:
  полный decode, 720×1280, звук, длительность, SRT, изменение графики,
  отдельная зона субтитров — passed. Это не lip-sync тест.
- GUI запустился с заголовком 0.5.0; новые элементы списка и папки фото присутствуют
  в accessibility tree. Полный автоматический GUI-маршрут импорта не подтверждён:
  инструмент UI-автоматизации завершался таймаутом. Импорт 30 проверен через backend.

## Ограничения проверки

21 unit/integration tests не запускают ML. Реальный голосовой smoke — отдельная
проверка, не оценка тембра. Новая полная генерация LTX-ролика не выполнялась:
проверены импорты, зависимости и существующий вызов; не заявляем повторную
художественную проверку нового лица и артикуляции.

Сборка и tests проверены в существующих локальных окружениях. Чистая установка
всех моделей на другом Mac не проверялась. .app привязано к рабочему каталогу,
не является переносимым установщиком и не notarized.

Личные логи, записанный голос, фото и тестовые результаты не входят в исходники.
Секреты и персональные пути проверяются на allowlist-экспорте перед публикацией.

## Повторение

```sh
local-avatar/.venv-lipsync/bin/python -m unittest discover -s mac-app/tests -p 'test_*.py'
local-avatar/.venv-lipsync/bin/python mac-app/engine/doctor.py
local-avatar/.venv-lipsync/bin/python mac-app/tests/check_storyboard.py
./mac-app/build.sh
codesign --verify --deep --strict 'mac-app/build/Аватар Студия.app'
```

Перед реальной сдачей ролика: прослушать чистую речь, проверить все длинные паузы,
крайние положения головы и двухстрочных субтитров, лицо/артикуляцию, полный декод
и готовый монтаж. Сохранить human_review=pending до реального просмотра.
