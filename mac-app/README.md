# Аватар Студия 0.5.0

Нативное macOS AppKit-приложение: профиль аватара, сценарий, ESpeech-озвучка,
LTX-планы героя, анимированная графика и speech-first монтаж. Apple Silicon.
Собственный код — MIT; модели и внешние зависимости устанавливаются отдельно.

## Сборка

Из корня рабочего каталога:

```sh
./mac-app/build.sh
open 'mac-app/build/Аватар Студия.app'
```

Нужны macOS Command Line Tools. Иконка генерируется из векторного исходника.
.app содержит абсолютный путь рабочего каталога, но не модели и окружения.
После перемещения пересоберите. Это исходный проект с локальной ad-hoc подписью,
не notarized установщик. Установка окружений: [SETUP.md](SETUP.md).

## Аватар и голос

«Подключить папку аватара» читает avatar.json version=1 с полями name/photo/audio/text.
Пути media разрешаются относительно профиля. Или создайте профиль через мастер GUI:
портрет, чистая запись 2–30 секунд, точные слова записи. Используйте своё лицо и голос
либо материалы с разрешением человека. Никакие профили в открытый репозиторий не включены.

Версия 0.5.0 использует **ESpeech RL-V2**, словарь ударений и TTS-написания, темп 1.0.
Ранее общий движок использовал Qwen; отдельные ролики уже имели ESpeech-обход.
Перед видео прослушайте «Только голос». Контроль пауз >=0.85 секунды останавливает
задачу до LTX; автоматически ускорять голос или заполнять хронометраж тишиной нельзя.

## Список сценариев и случайные фото

1. Подключите профиль аватара с нужным голосом.
2. «Загрузить список сценариев…»: JSON, CSV или несколько TXT-файлов. В предпросмотре
   проверьте названия. Формат JSON — массив объектов title/script (также source/speech)
   или {"items":[...]}; CSV — title,script. [Примеры](examples/scenarios.json).
3. При желании выберите «Папка случайных фото». Для каждого ролика будет выбрано одно
   фото верхнего уровня; возможны повторы. Голос остаётся из профиля. Используйте
   разные фотографии одного человека. Повреждённые изображения пропускаются.
4. «Создать голос» либо «Создать видео» запускает очередь. Все сценарии проверяются
   до старта моделей. Максимум 100 сценариев; до 5 MB на файл импорта.
5. Результаты — videos/exports/<проект>, задания — mac-app/jobs/, библиотека —
   mac-app/data/. Выбранное фото копируется в задание, поэтому продолжение не меняет выбор.
6. Ошибка ставит очередь на паузу. «Продолжить очередь…» → папка batch-* с batch.json.
   Завершённые задания пропускаются. «Остановить» прерывает worker; очередь сохраняется.
7. «Одиночный режим» возвращает редактор. Папка случайных фото работает и с одним текстом;
   очистите её поле, чтобы использовать портрет профиля.

Не используйте JSON со смешанными полями поста/режиссуры как текст речи: parser берёт
только source/script/speech. Поле script из подготовленного пакета 30 разборов совместимо.

## Одиночная работа и результат

Вставьте простой текст или структурированный сценарий `СЦЕНА 1 … Озвучка: «…»`.
«Подготовить сценарий» показывает план. Исходный промпт сохраняется отдельно от речи.
Лимиты: 50 000 символов исходника, 1500 символов речи, 350 символов в реплике, 90 с.
Время сцен следует озвучке. Графика иллюстрирует текст; команды и инструкции из него
не исполняются. Субтитры группируются приблизительно внутри реплик, без word alignment.

720×1280, 24 fps, H264/AAC. Герой целиком вписывается в отдельный viewport; субтитры
ниже него. Сходство, артикуляция и качество композиции требуют человеческого просмотра.
Отчёт содержит human_review=pending: технический decode не равен художественному QC.

## Проверки и обслуживание

```sh
local-avatar/.venv-lipsync/bin/python mac-app/engine/doctor.py
local-avatar/.venv-lipsync/bin/python -m unittest discover -s mac-app/tests -p 'test_*.py'
local-avatar/.venv-lipsync/bin/python mac-app/tests/check_storyboard.py
```

Qwen-исходник сохранён только для истории; production fallback на него не выполняется.
Вычисления последовательные, GPU защищён lock; cooperative cooling не использует SIGSTOP.
Приложение не выключает компьютер. caffeinate удерживает от сна по бездействию.
Ручной сон и закрытие крышки могут прервать процесс.
