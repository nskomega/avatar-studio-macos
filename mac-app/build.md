# Сборка 0.5.0 (build 9)

Из корня проекта: `./mac-app/build.sh`. Нужны macOS Command Line Tools.
Компилируются AppKit GUI и векторный генератор иконки; iconutil создаёт ICNS.
Сборщик записывает Info.plist с версией, bundle identifier и абсолютным путём
рабочего каталога, затем ставит локальную ad-hoc подпись.

Результат: mac-app/build/Аватар Студия.app. Модели, окружения и медиа не включены.
Не перемещайте рабочий каталог без пересборки. Приложение не notarized и не имеет
Developer ID подписи. Не распространяйте локальный .app, содержащий ваш путь:
для открытого проекта публикуются только исходники и инструкция сборки.

Перед повторной сборкой закройте старую GUI-сессию. При аргументах executable
переключается в Python CLI, не открывая NSApplication. Обёртка mac-app/studio
использует собранный executable. Иконка не требует личных изображений.
